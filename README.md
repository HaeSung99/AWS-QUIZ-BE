# AWS Quiz BE

## 기능 요약
운영 중인 AWS Quiz 백엔드입니다.

## 핵심 기능
- 인증/권한
  - 회원가입, 로그인, JWT 인증
  - 이메일 인증코드 발송/검증
  - admin/user 권한 분리

- 이메일 인증 보안
  - 이메일 재발송 쿨다운(120초)
  - IP 기준 발송 제한(1시간 10회, 일 20회)

- 퀴즈/학습 데이터
  - 문제집 문항 조회 API
  - 제출 결과 저장, 풀이 완료 문제집 저장
  - 문제집 정답률 집계(최초 제출 기준 정책)

- 방문/운영 통계
  - 일/월 접속자수, 가입자수 집계
  - 문제집 정답률 통계 제공
  
- 관리자 API
  - 공지 CRUD
  - 문제집 CRUD
  - 문항 CRUD
