# AWS Quiz KR — Backend

NestJS 기반 AWS 자격증 문제집, 퀴즈 API입니다. MongoDB(문제집, 문항 등)와 MySQL(TypeORM: 임베딩, 풀이 기록, 통계 등)을 함께 사용합니다.

## 기술 스택

- NestJS, TypeScript
- MongoDB (Mongoose) — 공개 문제 메타, 문항 본문
- MySQL (TypeORM) — 사용자, 인증 로그, 문항 임베딩, 풀이 시도, 방문 로그 등
- JWT, Passport, 이메일 발송
- OpenAI API — 텍스트 임베딩(`embeddings`), 약점 코멘트용 채팅(`chat.completions`)

---

## AI, 임베딩, 약점 분석

문항 텍스트를 OpenAI 임베딩으로 벡터화해 MySQL `question_embeddings` 테이블에 저장하고, 코사인 유사도로 활용합니다.

### 문항 임베딩 저장, 동기화

- 공개 문항에 대해 문제 본문 등으로 임베딩을 만들고, `questionId` 단위로 저장합니다.
- 관리자가 문제집, 문항을 저장, 수정하면 해당 문제집/문항에 대해 임베딩 동기화가 호출되어 내용이 바뀐 경우 다시 계산합니다.

### 이용자 약점 벡터 → 유사 문제 추천 (`getRecommendedQuestions`)

1. 사용자의 최근 50개 문항 풀이 기록을 사용합니다.
2. 기록이 50개 미만이면 약점 기반 추천은 제공하지 않습니다. (코드 상 상수 `WEAKNESS_ANALYSIS_REQUIRED_ATTEMPTS = 50`)
3. 오답은 “약점 방향”으로, 정답은 완화 신호로 가중해 약점 벡터를 만듭니다.
4. 공개 문항 임베딩과 유사도를 매기되, 같은 문제 반복 시도, 최근 정답 여부 등으로 페널티를 줘 다양성을 조절합니다.
5. 목표 자격증이 있으면 해당 자격증 범위 안의 문항만 후보로 삼습니다.
6. 각 추천에 사용자에게 보여 줄 간단한 추천 사유 문자열을 붙입니다.

관련 엔드포인트 예: 로그인 사용자 기준 `GET .../me/recommended-questions` (프록시 경로는 `auth` 모듈 라우팅을 참고).

### AI 약점 코멘트 (`getWeaknessComment`)

- 최근 풀이 패턴을 유형별로 요약하고, 위에서 구한 추천 문제 특징과 함께 프롬프트를 구성합니다.
- 민감한 개인 식별 정보 없이 학습 패턴만 LLM에 넘깁니다.
- 동일 사용자, 당일(KST)에는 결과를 DB에 캐시해 하루 1회만 토큰을 소모합니다.

### 관리자: 카테고리 추천 (`recommendQuestionCategory`)

- 작성 중인 문제 설명을 임베딩하고, DB에 있는 기존 문항 임베딩과 유사도를 비교합니다.
- 관리자가 넘긴 허용 카테고리 목록 안에서만 후보를 두어, 실제 서비스에 쓰는 카테고리 문자열과 정합되게 추천합니다.

### 오늘의 문제 (`getDailyQuestions`)

- 임베딩이 아니라 날짜, 사용자, 목표 자격증을 시드로 한 결정적 랜덤으로 문항을 고릅니다.

## 핵심 기능 (요약)

- 인증, 권한: 회원가입, 로그인, JWT, 이메일 인증 코드 발송, 검증, admin/user 분리
- 이메일 인증 보안: 재발송 쿨다운(120초), IP 기준 발송 제한(1시간 10회, 일 20회)
- 퀴즈, 학습: 문제집, 문항 조회, 제출, 결과 저장, 풀이 완료 문제집 기록, 문제집 정답률 집계(최초 제출 기준)
- 통계, 방문: 일, 월 접속, 가입 집계, 문제집 정답률 통계
- 관리자 API: 공지, 문제집, 문항 CRUD, 임베딩 동기화 연동, 카테고리 AI 추천
